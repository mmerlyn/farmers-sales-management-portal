# Sales Management System for Farmers

A web-based portal designed to **digitize and organize monthly sales data** for smallholder farmers. By replacing handwritten bills into structured, searchable records, the system enables farmers to track their produce sales and generate meaningful reports - empowering them with insights for **strategic seasonal planning** and **data-driven decision making**.

## Problem Statement

In India, a large number of farmers sell their produce on a **daily basis**, but receive only a **monthly handwritten bill** from shopkeepers. These paper records:

- Are difficult to store and retrieve over time
- Lack structure for meaningful analysis
- Often leave farmers unaware of sales patterns or trends

This project addresses these issues by:

- **Digitizing monthly bills** into a secure, searchable database
- Enabling **report generation** by crop, price, date, and vendor
- Laying the foundation for **future analytics and crop recommendation**

This empowers farmers with better control over how and when they sell their produce.

## Technology Stack

- **Frontend**: HTML, CSS
- **Backend**: PHP
- **Database**: MySQL

## Key Features

- Upload and manage monthly sales data
- View, sort, and filter bills by crop, rate, shop, and date
- Generate summaries for total income, best-selling crops, etc.
- Store historical sales data securely
- Scalable backend for analytics and future features like price prediction or crop suggestions
